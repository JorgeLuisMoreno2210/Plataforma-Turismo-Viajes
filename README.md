# Agencia de Viajes Online — Catálogo de Destinos y Reservas

Plataforma web moderna diseñada para una agencia de turismo y viajes en línea. Permite a los usuarios explorar destinos nacionales e internacionales, comparar paquetes vacacionales, consultar itinerarios y gestionar solicitudes de reserva de manera rápida y visual.

## Características principales
* **Catálogo interactivo de destinos:** Exhibición visual de lugares turísticos, planes todo incluido, tarifas y detalles de cada experiencia.
* **Búsqueda y exploración intuitiva:** Navegación estructurada por categorías, promociones y temporadas para facilitar la elección del viaje ideal.
* **Formulario de reserva y contacto:** Módulo interactivo para solicitar cotizaciones personalizadas, seleccionar fechas y confirmar reservas.
* **Diseño atractivo y responsivo:** Interfaz adaptable a computadores, tabletas y teléfonos móviles con enfoque en la experiencia del viajero.

## Lenguajes y herramientas utilizadas
* **Desarrollo Web:** HTML5, CSS3, JavaScript
* **Control de versiones:** Git y GitHub Desktop
